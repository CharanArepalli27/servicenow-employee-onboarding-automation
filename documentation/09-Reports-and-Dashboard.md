# Reports and Dashboard

Reports and dashboards are used in the Employee Onboarding Automation project to monitor onboarding requests, track pending fulfillment tasks, and view completed onboarding requests.

The project contains three reports and one dashboard.

---

## 1. Onboarding Requests by State

### Purpose

Display the current state distribution of Employee Onboarding Requests.

### Configuration

**Table:**  
Requested Item [sc_req_item]

**Report Type:**  
Donut

**Group By:**  
State

### Filter

```text
Item = New Employee Onboarding Request
