# Update Set

This folder is intended to contain the ServiceNow Update Set used to move the Employee Onboarding Automation project between ServiceNow instances.

## Project Update Set

**Update Set Name:**

Employee Onboarding Automation

**Purpose:**

Capture the configuration changes required for the Employee Onboarding Automation project so that the configuration can be transferred to another ServiceNow instance.

---

## Components Included

The Update Set is intended to capture the configuration created for the project, including applicable:

- Service Catalog configuration
- Catalog Item
- Variable Sets
- Catalog Variables
- UI Policies
- Catalog Client Scripts
- Flow Designer configuration
- Subflow configuration
- Notifications
- Reports
- Dashboard configuration
- Other captured application configuration

---

## Creating the Update Set

In the development ServiceNow instance:

1. Navigate to **System Update Sets → Local Update Sets**.
2. Click **New**.
3. Enter the Update Set name:

Employee Onboarding Automation
